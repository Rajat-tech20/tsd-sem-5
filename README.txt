HOW TO CONNECT YOUR OWN WEBSITES
1. Copy each practical's folder into the "practicals" folder (practical-1 ... practical-5).
   Each folder must contain its own index.html.
2. Open js/practicals.js and set each "url":
     HTML/CSS/JS practical -> "practicals/practical-1/index.html"
     React practical       -> "https://your-app.vercel.app"  (deployed link)
3. Open index.html in a browser. Clicking a card opens that practical.
